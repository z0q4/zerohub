# ZeroHub

A modern, minimal hub for managing projects and resources with zero complexity.

## Features

- Lightweight and fast
- Easy to set up and configure
- Minimal dependencies
- Clean and intuitive interface
- Modular architecture

## Installation

```bash
Execute o comando de instalação (PowerShell - admin):

winget install --id Git.Git -e --source winget

Feche este terminal do PowerShell e abra uma nova janela.

cd C:\Users\???\Documents
git clone https://github.com/z0q4/zerohub.git

Feche esta janela do PowerShell e abra uma nova janela.

cd C:\Users\???\Documents\zerohub
winget install --id OpenJS.NodeJS.LTS -e --source winget

Feche esta janela do PowerShell e abra uma nova janela.

cd C:\Users\???\Documents\zerohub

npm install

npm start

```

## Usage

```bash
#install NVM if you dont have it;
nvm install 22

nvm use 22

#install dependecies;
npm install
#start
npm start
#or this on root
npx electron .
```
