# ZeroHub

A modern, minimal hub for managing projects and resources with zero complexity.

## Features

- Lightweight and fast
- Easy to set up and configure
- Minimal dependencies
- Clean and intuitive interface
- Modular architecture

## Installation

```bash
git clone https://github.com/z0q4/zerohub.git
cd zerohub
```

## Usage

```bash
#install NVM if you dont have it;
nvm install 22

nvm use 22

#install dependecies;
npm install
#start
npm start
#or this on root
npx electron .
```
