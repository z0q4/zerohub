# ZeroHub map data

The generated GeoJSON files in this directory are derived from Natural Earth
public domain datasets, via the Natural Earth Vector repository:

https://github.com/nvkelso/natural-earth-vector

Natural Earth data is public domain. The generated files keep only compact
geometry and a small subset of descriptive properties needed by the local
ZeroHub map.

Generated by:

```bash
python3 scripts/prepare-map-data.py
```

## IBGE municipality boundaries

Brazilian municipalities are resolved on demand against the IBGE Localidades
catalogue by state and municipality code, then obtained from the IBGE Malhas
API at intermediate simplification. The source is Instituto Brasileiro de
Geografia e Estatística (IBGE); attribute it when using the data. The API
returns the most recent available mesh when no period is specified, so the
application does not claim a particular reference year. IBGE describes these
meshes as simplified, and its municipal-boundary documentation describes
limitations in the precision and legal interpretation of boundaries.

- API documentation: https://servicodados.ibge.gov.br/api/docs/malhas?versao=3
- Localities catalogue: https://servicodados.ibge.gov.br/api/docs/localidades
- Technical and legal information: https://www.ibge.gov.br/geociencias/organizacao-do-territorio/malhas-territoriais/15774-malhas.html

The fetched municipality catalogue and geometries are cached in memory for
up to 24 hours; they are not bundled as new assets or stored in case files.

## Recife neighborhoods and streets

For the verified IBGE municipality 2611606 only, selected neighborhood
boundaries come from the Prefeitura do Recife's 2023 neighborhood limits.
Street geometry comes from its Trechos de Logradouros dataset, matched by
official street code against the Trechos de Logradouros por Bairro table.
These datasets are published under the Open Data Commons Open Database
License (ODbL); attribution: Prefeitura do Recife, Portal de Dados Abertos.
The street geometry describes the complete mapped street, which can extend
beyond the selected neighborhood. Coverage and administrative boundaries
are subject to the published datasets, and unavailable or ambiguous matches
are not drawn.

- Neighborhood limits: https://dados.recife.pe.gov.br/dataset/mapas-de-limites-e-divisoes-territoriais/resource/d5f956ce-7e1f-4c74-839b-06cb490c3721
- Street geometry: https://dados.recife.pe.gov.br/dataset/area-urbana/resource/6be90377-7b6d-483c-9b58-f7f34401ee6a
- Street/neighborhood association: https://dados.recife.pe.gov.br/dataset/area-urbana/resource/15f820ba-6370-4d49-af5e-4eec6e559bf6
- ODbL: https://opendatacommons.org/licenses/odbl/1-0/

These files are downloaded only after selection and cached in memory for up
to 24 hours. The first street lookup can download approximately 14 MB. The
validated street data is also stored as a compressed, versioned cache in the
application's user-data cache directory, with a 24-hour expiry, so subsequent
app launches can reuse it. Invalid or expired cache entries are ignored and
reloaded. The application does not redistribute the files or save their
geometry in cases; the cache contains only public data.
